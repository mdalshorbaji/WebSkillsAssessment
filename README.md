# WebSkillsAssessment

This project is a web-based CTF challenge used to assess students' web development skills before joining the Web Security course.

## Requirements

* Node.js (v14 or higher)
* npm

## Installation

Clone the repository:

git clone <repo-link>

cd WebSkillsAssessment

Install dependencies:
npm install

## Run the Project

Start the server:

npm start

Open your browser and go to:


#Challenge

* The application contains 6 levels
* Each level includes one hidden flag
* Flag format: `flag{...}`


## Submission

Students must submit a screen recording video that shows:

* How each level was solved
* The flag for each level
* A brief explanation of the issue
* A suggested fix


## Notes

* Use browser and DevTools only
* Do not use automated tools
* Do not test on external websites
