Web Development Entry Assessment

Web Skills Assessment

This assessment measures the student’s current web development skills before joining the Web Security course.

Instructor: Eng.Mohammad AlShorbaji

Start Challenge

Assessment Requirements

  • You must complete all 6 levels.
  • Each level contains one hidden flag.
  • Flag format: flag{...}

Flag format: flag{example}

Video Submission

You must submit a screen recording video.

  • Show how you solved each level.
  • Show the flag clearly.
  • Explain the issue and how to fix it.

Rules

  • Use only the browser and built-in developer tools.
  • Do not use automated scanners or attack tools.
  • Do not test or attack any external website.
  • Submitting flags without explanation is not accepted.
  • Your answers must describe your own steps.

Level 1: Page Inspection

Task: Inspect the page source and identify the hidden flag.

Required in report: Explain where the flag was located and why sensitive data should not be placed in client-side files.
